#  Red-Black Tree Insertion Simulation

An interactive web-based visualization of **Red-Black Tree insertion** that demonstrates how nodes are inserted, recolored, and rotated to maintain the properties of a Red-Black Tree.

##  Live Demo

🔗 [View the Red-Black Tree Insertion Simulation](https://faishal080.github.io/RB-Tree-Insertion-Simulation/)

## About the Project

A **Red-Black Tree** is a self-balancing Binary Search Tree (BST) that maintains balance using:

- Node coloring
- Recoloring
- Left rotations
- Right rotations

This project provides a visual way to understand what happens during the insertion of nodes into a Red-Black Tree.

Instead of only looking at the algorithm in code, the simulation allows users to observe the tree's structure and balancing process interactively.

##  Features

-  Interactive Red-Black Tree visualization
-  Insert nodes dynamically
-  Visual representation of red and black nodes
-  Demonstrates tree rotations
-  Shows recoloring during balancing
-  Useful for learning Data Structures and Algorithms
-  Runs directly in a web browser
